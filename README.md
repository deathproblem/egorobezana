# Egor OS 98 — Mogging & Sub 3 Edition 🤫🧏

Ретро-операционная система с трендовыми тикток-мемами про Егора, луксмаксинг и мьюинг.

## 🤫 ГЛАВНАЯ НОВАЯ ФИЧА: «Я ТЕБЯ МОГНУ!» (MOG BATTLE 1v1)
- **Кнопка «🗣️ Я ТЕБЯ МОГНУ!»**:
  - Егор поворачивается боком, натягивает мьюинг-жест 🤫🧏 и голосом синтезатора кричит: *«Я тебя могну! Смотри на мой джолайн!»*.
- **Кнопка «🤫 BYE BYE...»**:
  - Врубается глубокий саб-бас дроп (Phonk / Lumi Athena vibe), экран темнеет и вылетает надпись **«BYE BYE... ЕГОР БЫЛ ЖЕСТОКО ЗАМОГАН»**.
- **Mog-Meter**: шкала ауры падает у Егора до 4%, пока соперник уничтожает его своим взглядом охотника.
- **Выбор соперников, которых Егор безуспешно пытается могнуть**:
  - *Ты (Гигачад)*
  - *Кот Мурзик (природный positive canthal tilt)*
  - *Холодильник Атлант (ширина плеч 90 см)*
  - *Артём Дурак (битва двух титанов)*
  - *Шаурма с сыром*
